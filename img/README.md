# Visual assets

The current public site uses the existing Aurorael portrait and icon from the project's public repository through their raw URLs in `css/styles.css` and `index.html`.

If you want the site to be fully self-contained, copy your existing files here as:

- `img/aurorael.PNG`
- `img/hegel.png`

Then replace the two raw image URLs in `css/styles.css` / `index.html` with the corresponding local paths.
